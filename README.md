# CampusResourceHub
CampusResourceHub is a web application that helps a college manage shared resources and their bookings.

The system has three main technical parts.

First, the frontend is built using React and CSS. It allows students to browse resources and make bookings, while administrators can manage resources and view booking information.

Second, the backend is built using Python and Flask. It receives requests from the frontend, checks permissions, processes operations, and communicates with the database.

Third, the database stores information such as users, resources, departments, and bookings so that the application can retrieve it whenever required.

The application can also use booking information to understand resource demand. Cloud infrastructure can provide a way to host the application and make it accessible to users over a network.

Our overall goal is to make campus resource management more organised, accessible, and efficient.
